# 益智游戏 - 儿童认知启蒙

为5岁儿童打造的认知启蒙游戏,通过游戏化学习建立颜色、形状、数学等基础知识认知。

## 🎯 产品特点

- 🎮 **寓教于乐**: 游戏化设计,让学习变得有趣
- 📱 **iPad优化**: 针对iPad Safari浏览器优化,适配旧设备
- 🔒 **安全可靠**: 无广告、无付费、数据本地存储
- 🎨 **视觉吸引**: 色彩丰富、形象可爱的界面
- 👨‍👩‍👧 **家长监控**: 家长面板查看学习进度

## 🚀 快速开始

### 方法一: 直接打开 (推荐)

1. 下载或克隆整个项目到本地
2. 用浏览器打开 `index.html` 文件
3. 点击任意位置开启声音
4. 选择"颜色星球"开始游戏!

### 方法二: 本地服务器

```bash
# 使用Python的HTTP服务器
python -m http.server 8000

# 或使用Node.js的http-server
npx http-server -p 8000
```

然后在浏览器访问: `http://localhost:8000`

## 🎮 游戏玩法

### 颜色星球 (MVP)

- **第1关**: 基础色识别 - 识别红、黄、蓝、绿
- **第2关**: 颜色分类 - 将物品按颜色分组
- **第3关**: 颜色配对 - 找出相同颜色
- **第4关**: 深浅色区分 - 区分同一颜色的深浅
- **第5关**: 综合挑战 - 综合运用颜色知识

### 评分系统

- ⭐⭐⭐ **3星**: 正确率 ≥ 90%
- ⭐⭐ **2星**: 正确率 ≥ 70%
- ⭐ **1星**: 正确率 ≥ 50%
- ❌ **0星**: 正确率 < 50% (需要重试)

### 家长功能

1. 点击首页右上角"家长查看"
2. 完成算术验证(防止儿童误操作)
3. 查看学习统计和进度
4. 可以重置进度

## 💾 数据存储

- 所有进度保存在浏览器 **LocalStorage** 中
- **不会丢失**: 关闭浏览器后再打开,进度自动恢复
- **注意**: 清理浏览器缓存会清空所有进度!

## 🔧 技术栈

- **前端**: 原生JavaScript (ES6+)
- **样式**: CSS3 + Flexbox
- **存储**: LocalStorage
- **音频**: Web Audio API
- **动画**: CSS Transitions
