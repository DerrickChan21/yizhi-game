# 音频文件说明

这个目录用于存放游戏的音频文件。

## 需要的音频文件

### 基础音效
- `correct.mp3` - 答对音效 (欢快,0.5秒)
- `error.mp3` - 答错音效 (柔和,0.5秒)
- `click.mp3` - 点击音效 (清脆,0.2秒)
- `unlock.mp3` - 解锁音效 (庆祝,1秒)
- `celebrate.mp3` - 庆祝音效 (欢呼,2-3秒)

### 赞扬语音
- `praise_1.mp3` - "真棒!"
- `praise_2.mp3` - "太厉害了!"
- `praise_3.mp3` - "你真聪明!"

### 题目音频 (可选)
- `color_1_q1.mp3` - "听一听,找出红色"
- `color_1_q2.mp3` - "哪个是蓝色的?"
- `color_1_q3.mp3` - "找出黄色"
- `color_1_q4.mp3` - "点一点绿色"
- `color_1_q5.mp3` - "红色在哪里?"

## 音频规格

- **格式**: MP3
- **比特率**: 128kbps
- **采样率**: 44.1kHz
- **声道**: 单声道 (节省空间)
- **文件大小**: 每个文件 < 30KB

## 免费音频资源

可以使用以下网站获取免费音效:

1. **Freesound** (https://freesound.org/)
   - 搜索: "correct", "success", "children game"
   - 注意选择 Creative Commons 授权的音频

2. **Zapsplat** (https://www.zapsplat.com/)
   - 分类: Children's sounds, Game sounds
   - 免费使用,需署名

3. **Mixkit** (https://mixkit.co/free-sound-effects/)
   - 完全免费,无需署名
   - 质量高

## 使用说明

1. 将下载或制作的音频文件放在这个目录
2. 确保文件名与上面列出的名称一致
3. 音频文件应该是短小精悍的,避免过长
4. 测试在iPad Safari上能否正常播放

## 临时方案

如果没有音频文件,游戏会正常运行,只是没有声音。可以后续添加音频资源。
